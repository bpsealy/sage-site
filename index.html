How Sage works

Sage learns from every hunt and fish you log, then scores your upcoming days against that history so you know when your spots are actually worth a sit. This page walks through every part of the app in detail, with real screens from Sage alongside each step.

Use the bar above to jump to a section, or just scroll — everything follows the order you'd naturally set the app up in.

Spots & Properties

Properties are the land you hunt — a lease, a family farm, public ground. Spots are the individual stands, blinds, or waypoints inside that land. Every spot keeps its own history, its own preferred wind, and its own score.

1 Open Spots & Properties

From the Hunting tab, tap the pin icon in the top right to open the map, or use the gear icon next to it for settings. Spots & Properties lives under the map view's toolbar — it lists every property you've created, any Camps you belong to, and every active spot, with an archived section tucked below.

The Spots & Properties list — Properties, Camps, and Active Spots each get their own section.
2 Add a spot or a property

Tap the + in the top right. You'll get three choices: Add spot to drop a new pin, New property to create a piece of land to organize spots under, or New camp to start a shared workspace (covered in the Camp section).

The + menu — pick the one that matches what you're setting up.
3 Create a property

Give it a name (your lease name, "Home," a family farm), then set its location on the map. A property's location is pinned once and stays static — every spot inside that property shares this one location for weather and wind, so pin it at the center of the land, not any one stand.

If you've already got spots sitting around ungrouped, you can check them off right here under Add existing spots to fold them into the new property immediately.

Creating a property — name it, pin its location, and optionally sweep in existing spots.
A property's pinned location drives the weather and wind shown for every spot inside it, so accuracy here matters more than it looks like it would.
4 Create a spot

Choose Add spot, name it, and pick a stand type — Box, Ladder, Ground Blind, Climber, Lock-On, Tripod, Food Plot, or Natural. Further down, set the habitat details that actually apply: cover type, water features, terrain, food and attractant sources, and structure or edge features like a funnel or fence line. None of it is required, but the more you fill in, the more Sage has to work with later.

Name and stand type at the top of the form.
Habitat tags and the location picker further down.
5 Set the spot's location

Scroll to the map at the bottom of the New Spot form. Tap Use current to drop the pin where you're standing, pick From saved to reuse a previously saved location, or tap the map itself to open the full-screen location picker and drag the pin to the exact spot.

The full-screen location picker — pan the map until the pin sits exactly where you want it, then Done.
6 Set the spot's optimal wind

Under Optimal Wind (From), tap every compass direction this stand hunts well in. This is separate from live wind data — it's you telling Sage which winds actually work for this stand's setup, so the app can flag when today's forecast wind lines up.

The wind grid on the Edit Spot screen — N is selected here, and Selected/Clear tracks your picks.
You can select more than one direction if a stand hunts well from several winds. Tap Clear to start over.
7 Assign a spot to a property

On the Edit Spot screen, the Property row shows the spot's current assignment — "Not assigned" if it's still ungrouped. Tap Assign to open the property picker: choose an existing property, tap Ungrouped to remove it from all properties, or tap Create new property to build one on the spot without leaving this screen.

The property picker — Ungrouped is always available if a spot doesn't belong under any property.
8 Edit an existing spot

Open any spot's detail page and tap the pencil icon top right. Everything set at creation — name, stand type, optimal wind, property, camera assignment, notes, and every habitat tag — is editable here, and Save writes the changes back immediately.

9 See a spot's full history

Every spot's detail page shows today's score, its best window, and why — a wind cone compass shows the live wind against the stand's optimal directions, and tags like time of day or temperature show which factors are matching in your favor. Below that, log counts for the spot break out into three tabs: Sightings, Logs, and Bucks, each scrollable in place.

Today's score and why, at the top of every spot.
The Logs tab — every hunt logged at this spot.
The Sightings tab — every buck seen here, and when.
The Bucks tab — target bucks associated with this spot.
10 Archive a spot

From the Hunting list, swipe left on a spot and tap Archive Spot. Archiving keeps the spot's history intact but pulls it out of active scoring and off the map — use it for a stand you've pulled or a lease you've dropped, not for one you're just not hunting this week.

Swipe left on any spot in the list to archive it.
Archived spots still show up on the Spots & Properties screen under "Show archived" if you need to bring one back.

Target Buck

Target Buck tracking follows one specific deer across seasons — every sighting, every camera hit, and a forecast scored against that buck's own pattern, not just the spot's.

1 Open Target Bucks

From the Hunting tab's bottom row, tap Bucks. Every buck you're tracking shows up under Active, newest sightings first. Bucks tagged [SEED] are demo data — clear it from a buck's detail page once you've got real ones of your own logged.

Bucks sits in the bottom row of the Hunting tab.
The Target Bucks list — active bucks with sighting counts and last-seen info.
2 Add a new target buck

Tap the + in the top right. Give it a name, optionally add a photo (from a trail cam hit or your camera roll), set an estimated age, and pick the spot where you first sighted him. The button in the top right starts as Add Name — that's telling you what's still needed, not a separate action. It becomes an active Save once you've typed a name.

Creating a new target buck.
3 Log a sighting

From a buck's detail page, tap Log Sighting. Add up to 5 photos, confirm the location (defaults to the spot you're logging from), set the time, bump the count if multiple animals were with him, and add notes. Every sighting you log feeds that buck's pattern data immediately.

Logging a sighting — count handles multiple animals in one sighting.
4 See a sighting's conditions

Tap any sighting in a buck's list to open its detail. Weather conditions are logged both 2 hours before and at the sighting — temperature, pressure, wind, and cloud cover — so you can see exactly what was happening when he showed up, not just the average for the day.

Sighting Detail — conditions before and at the moment he was seen.
Delete Sighting is available here if one was logged in error — it won't affect the rest of the buck's history.
5 Read a buck's overview

The top of every buck's detail page shows total sightings, first sighted, and last seen with location for each. Below that, a Forecast Match card scores today specifically for the spot he's most associated with — same 0–100 score and wind cone you'd see on that spot's own page.

A buck's overview — sighting history and today's forecast match in one place.
6 Check his pattern

The Patterns section below the forecast card is specific to this buck, not the spot in general — time-of-day activity built from his own sighting history. Sage flags it as preliminary until there's enough data logged to be confident in it.

7 Check his 7-day forecast

Tap See 7-Day Forecast on the Forecast Match card. It breaks each day down the same way the app scores any spot — a full factor list of what's working in your favor and what's off-pattern, from wind direction down to solunar and cold front proximity.

The full week, broken down factor by factor.
8 Edit a target buck

Tap Edit from the buck's detail page. Everything set at creation — name, photo, estimated age, primary spot, first sighted date, and notes — is editable here.

Editing a buck — Change Photo and Remove sit right under the current photo.
9 Archive or delete a buck

Scroll to the bottom of a buck's detail page. Archive Buck pulls him out of the active list without losing any sighting history — use this once he's been taken or you've stopped tracking him. Archived bucks show Unarchive Buck instead, so you can bring one back. Delete Buck is permanent.

Active — Archive Buck.
Archived — Unarchive Buck instead.

Trail Cam

Trail cam photos aren't just stored in a gallery — deer tallied from your cam hits feed directly into a spot's Pattern Match score. Import happens as a batch, straight from your camera app's share sheet.

1 Share photos from your camera app

From your trail camera app (Reveal shown here, but any app that can share photos works), select the photos you want to bring in and tap Share. Tap the Sage icon in the share sheet.

Sage shows up right in the share sheet — no separate upload step.
2 Confirm the batch

Sage opens straight to a Send to Sage screen showing every photo about to come in, with an optional quick note for the batch (handy for "split G2 camera" type context). These photos will sit in Sage's Camera List until you assign them to a spot — nothing scores yet.

Confirming the batch before it lands in Sage.
3 Import from the Hunting tab

Back in Sage, the Hunting tab shows a banner — "X trail-cam photos ready to import" — as soon as a batch is waiting. Tap it to continue.

The import banner sits right above current conditions.
4 Confirm which photos come in

Photos are grouped by burst. If you already picked through them in your camera app, everything's pre-checked — tap to uncheck anything that snuck in by mistake, then Continue.

Grouped by burst, already assigned to the spot you last used for this camera.
5 Tag each photo

For each photo, tag a Target Buck if one's in frame, and use the Other Deer in Frame counters — Mature Bucks, Young Bucks, Does, Fawns — to tally everything else. This tally is what feeds the spot's score, so it's worth doing even on photos with no target buck. Skip is always there for a blank or bad frame.

Tagging photo 2 of 10 — counts feed the spot's score directly.
6 Tag a target buck from a photo

Tap the Target Buck row to pick from your existing bucks, or tap New Buck Seen on Camera to create one on the spot without leaving the tagging flow.

Picking a buck mid-tag, or creating a new one from what the camera caught.
7 Manage cameras and suggested spots

Under Cameras, each device shows up by the ID parsed from its photo filenames — that's not a spot name, just a way to tell cameras apart. The Suggested Spot is only your last pick for that device; tap Change any time, since cameras get moved mid-season. Registered cameras below show which spot each is currently tied to and whether it's up to date.

Device IDs are just parsed filenames — the suggested spot is editable every time.
8 See trail cam activity in the Logbook

Filter the Logbook to Camera to see every import as its own entry — deer tallies, spot, weather at the time, all listed the same way a logged hunt is.

Every camera import lands in the Logbook alongside your hunts.

Camp

Camp is a shared workspace for a hunting group — shared spots, a shared logbook, shared target bucks, stand reservations, and Camp Insights that roll everyone's hunts together. Everything in this section applies inside a Camp; your personal spots and logbook stay separate.

1 Create a camp

From Spots & Properties, tap + and choose New camp. Give it a name and pin its location on the map — that location is shared by every spot in the camp for weather and wind, the same way a personal property works. You land inside the new camp immediately after creating it; invite members afterward from Camp Settings.

Same + menu as spots and properties.
Naming and pinning a new camp.
2 Invite members

Camp sharing runs on iCloud's native share sheet. Send the invite through Messages, Mail, or Copy Link, and set who can do what before you send it: Permission controls whether invitees can make changes or only view, and Adding People controls whether invited members can invite others too.

The native share sheet — send however's easiest.
Set permissions before you send the invite.
You can reopen this same share sheet any time to see who's in the camp, add more people, or tap Stop Sharing to end the camp for everyone but you.
3 Manage members and camp details

Camp Settings shows the full roster with join dates and roles, plus an overview of the camp's name, location, creation date, and season. Tap the red minus next to a member to remove them from the camp.

Camp Settings — overview, stats, and the full member list.
4 Configure camp settings

Further down, Rename Camp, Relocate Camp, and Import Spots sit under Camp. Season Start only organizes the Logbook and Insights into this-season versus past-seasons — it never affects Pattern Match scoring, since every hunt logged in any year still counts toward the score. Guest Policy controls whether members can bring guests when reserving a spot, with an optional cap per reservation and per year. Danger Zone holds Archive Camp and permanent deletion.

Season Start is organizational only — scoring always uses every hunt logged.
5 Add a spot to a camp

Same + menu, Add spot — name it, choose Hunting or Fishing, and set its location on the map. Camp spots use a lighter setup than personal spots; habitat detail and other tags can still be added later from the spot's own edit screen.

Adding a spot inside a camp.
6 View the camp map and scent cones

Tap the map icon in the camp header to see every spot plotted together. The Scent Cones toggle overlays each stand's wind cone against the current wind direction, so the whole group can see at a glance which stands are in play. The layers icon switches between Standard, Hybrid, Satellite, and Outdoors map styles.

Scent cones on for the current wind.
Switching map styles.
7 Browse camp spots and reserve a time

The camp's Hunting Home works like your personal one, with a member avatar stack up top and the same date tabs and forecast card. Each spot shows its score and status — Open · reserve a time in green, or Reserved by [name] in red if someone's already got it. Tap an open spot, pick a day on the calendar, choose AM, PM, or All Day, and tap Reserve.

One spot reserved, one open.
Reserving Plot 2 for the full day.
8 See a camp spot's detail

A camp spot's page looks like a personal spot's — badges, habitat, score, wind cone, factor chips — but the hunt count breaks out by member ("5 hunts · 4 by you, 1 by Asealy8"). Sightings and target buck tracking aren't built for camp spots yet; the app says so plainly rather than just showing a silent zero. A Camera at this spot toggle marks whether a trail cam covers it, and the Activity list mixes hunts and camera imports from every member, each tagged with who logged it.

Hunt counts attribute to whoever logged them.
Activity from the whole camp, one shared timeline.
9 Check a camp spot's pattern and score breakdown

The 7-day view names its own pattern source right at the top — "Pattern from top 2 of 4 hunts by deer count," for example — so it's clear the score is drawn from the group's most productive hunts, not just averaged across everyone. Tap into any day for the full factor breakdown. At a camp spot with a trail cam, Camera Activity shows up as its own factor row alongside wind, pressure, and solunar — recent cam hits genuinely feed the score here, not just the hunt logs.

The pattern source is stated up front.
Camera Activity as its own scoring factor.
10 Browse the Camp Logbook

Filter by Type, Spot, or Member. Reservations with no hunt logged show up as ghosted entries so the group can see who reserved a time and never followed up with a log — real hunt and camera entries show a deer-count badge and who logged them.

Reservations with no follow-up log stay visible, not hidden.
11 Track Camp Target Bucks

Bucks tracked at the camp level work the same as personal target bucks, with one addition: each shows where and who first spotted him — "First seen at Plot 2 · by Ben Sealy."

Camp bucks credit whoever spotted them first.
12 Read Camp Insights

Camp Insights rolls up everyone's hunts: total encounters, buck-to-doe ratio, median first-sight time, and best-performing spot by deer per hour, with a This Season / All Time toggle. Scroll further for pressure trend, best time-of-day window, moon phase performance, and activity broken out by month, by spot, and by member — so the group can see not just what's working, but who's finding it.

The camp's season at a glance.
By spot and by member, further down the same page.

Logging & Recap

Every hunt you log is what Pattern Match learns from. This section covers logging a hunt in detail, reviewing and sharing a single entry, reading your Hunting Insights, and generating a Season Recap.

1 Start a hunt log

Tap Log Hunt from the Hunting tab. Pick a spot, then set the species — Whitetail Deer, Turkey, Duck, Dove, Hog, Squirrel, Predator, or Other.

A fresh Log Hunt, spot not yet picked.
Species covers more than deer.
2 Log deer encounters and sighting time

Tally what you saw with the Mature buck / Young buck / Does / Fawns counters, then set First sighting and Sighting duration. These encounter counts are what feeds hunt-encounter stats in Insights later — logging them even on a slow sit is worth doing.

Encounters, first sighting, and the Tag a Target Buck shortcut.
3 Tag a target buck from the log

Tap Tag a Target Buck to open the picker and check off any bucks that were part of this sighting — multiple bucks can be tagged on one entry.

Tagging a buck directly from the hunt log.
4 Mark a harvest

Flip Deer harvested on to reveal Harvest Details: category (Mature buck, Young buck, Doe, Fawn), year class, weight, and full antler measurements — main beam and G1 through G4 for both sides, plus inside spread.

Full antler detail, tine by tine.
5 Rate the hunt and add notes or photos

Time in the Field locks in date, start, and end. Activity rates the animal movement you saw; Overall rates the day as a whole. Both feed straight into your average ratings in Insights. Notes and up to 5 photos are optional but worth doing on any hunt you'll want to remember.

Activity and Overall ratings drive your averages.
6 Review a logged entry

Open any entry to see its overall score, spot, duration, and Movement/Overall ratings up top. Scroll down for the same deer-encounter breakdown, harvest category/age/weight, and photos you logged.

Score and duration at the top.
Encounters, harvest detail, and photos further down.
7 See full trip conditions

Tap Show full conditions for a start/mid/end breakdown of everything — temperature, feels like, humidity, dew point, pressure, wind, gusts, cloud cover, visibility, UV index, and precipitation — plus the net change across the sit for temp, pressure, and wind.

Every condition, tracked at the start, middle, and end of the sit.
8 Edit or delete an entry

Tap Edit from an entry's detail page. Trip time is locked once logged, but spot, species, and every encounter count are editable. Delete entry sits at the bottom of the detail page if you need to remove one entirely.

Trip time is locked; everything else can be corrected.
9 Share or stop sharing a single hunt

Tap the share icon on any entry to send that one hunt through Messages, Mail, or Copy Link — no Camp required for this. Reopen the same share sheet later to stop sharing that entry.

Sharing one hunt, no Camp needed.
Stop Sharing ends it whenever you want.
10 Browse Hunting Insights

From the Hunting tab, tap Insights. Filter by Property, Spot, or Species, then check the At a Glance summary — trips, average rating, hours logged, best and worst hunts, top species — and Hunt Encounters for total animals seen, average per hour, and harvest rate.

Filters narrow every stat below to exactly what you're asking about.
11 Dig into conditions and patterns

Best Conditions compares your top 3 hunts against your bottom 3 across temp, pressure, wind, and clouds. Below that, Pressure Trend, Time of Day, and Moon Phase break your history down by what was actually working, each flagging your single best-performing window.

Top 3 vs bottom 3 conditions, side by side.
Time of day and moon phase, each with a flagged best window.
12 See spots, species, and recent trips

Further down, Spots and Species rank every one you've logged by trip count and average rating, and Recent Trips lists your latest entries with their score at a glance.

Every spot and species, ranked by how they've actually performed.
13 Generate a Season Recap

Sage flags recaps as Ready to wrap up once a season's worth of hunts is logged, grouped by species and year. Tap one to generate it.

Recaps ready whenever a season's logged.
14 Read and share a Season Recap

A recap opens with hunts, harvests, and hours logged, your Best Hunt, and a full harvest list with weight, spread, and age for each animal. Below that, Deer Seen breaks down every encounter across the season, and Conditions That Worked summarizes the pressure, wind, temperature, sky, and rut phase sampled from your top-rated hunts. Tap the share icon up top to send the whole recap out.

The season's headline numbers and every harvest.
Deer seen, conditions that worked, and the season's photos.

Fishing

Fishing works the same way hunting does — log trips, and Sage scores your upcoming days against what's actually worked at that spot, broken out by freshwater and saltwater.

1 Log a trip

From a spot's card, tap Log Freshwater Trip or Log Saltwater Trip depending on the water. Sage pulls in the weather and, where available, tide or river gauge data for that trip automatically — you just fill in what you caught.

Freshwater spots link to the nearest river gauge station.
Saltwater spots link to the nearest tide station instead.
2 Review a logged trip

Every entry shows your bite and overall ratings, what you caught, and the weather during the trip — start, midpoint, and end, so you can see how conditions shifted while you were out. Tap Show full conditions for the full breakdown, and scroll down for water depth, flow trend, and gauge height pulled from the linked station.

Catches and ratings sit right at the top of every entry.
Full conditions plus water depth, flow trend, and gauge height.
3 Your Fishing home screen

The Fishing tab opens on All Spots, showing your best Forecast Match across every spot along with today's bite window and solunar times. Tap a spot's pill to narrow everything on the screen down to just that spot — its own forecast match, water data, and season info.

All Spots shows your best match across every spot at once.
Pick a spot to see its own forecast match and water data.
4 Check Pattern Match

Tap into the Forecast Match card for a spot to see the full 7-day breakdown. Sage pulls your top trips by catch count at that spot and compares each upcoming day against those exact conditions — wind, pressure, temperature, cloud cover, tide or solunar timing, all of it. In your favor and Off-pattern tell you at a glance what's lining up and what isn't.

Saltwater pattern match, weighing wind, pressure, and tide.
A lower score still shows exactly why, condition by condition.
5 Browse your Logbook

Filter the Logbook to Fish to see every trip in one list — species, spot, catch count, rating, and the conditions at the time. Tap any entry to open its full detail.

Every fishing trip you've logged, newest first.
6 Open Fishing Insights

From the Logbook, tap Insights for a full stats breakdown — best and worst spots, top species by trip count, and best conditions comparing your top-rated trips against your bottom-rated ones. Scroll further for time-of-day and moon-phase breakdowns, plus a by-month chart showing exactly when your best trips happen.

Spots and species, ranked by rating and trip count.
Best time of day, best moon phase, best month — all data-driven.
Your top 3 trips vs. bottom 3, condition by condition.
7 Tide and water flow data

Saltwater spots link to the nearest NOAA tide station, freshwater spots to the nearest USGS river gauge. Tap the station name on any spot to pick a different one nearby, or open the linked station directly for a full tide curve or discharge and gauge height chart.

Every nearby tide station, pick whichever fits your spot.
Current tide, next high or low, and a 36-hour curve.
Same idea for freshwater — nearby USGS flow stations.
Discharge and gauge height over the last 7 days.
8 Browse the Fishing Calendar

Tap Fishing Season from the home screen to open the full calendar. Switch between Saltwater and Freshwater to see every species' seasonal pattern year-round, with a star rating and a plain-language note on what's working right now.

Freshwater — Bass in its Fall Feed-Up window right now.
Saltwater — Tarpon mid Migration Peak.

Weather & Conditions

Every score in Sage is built on the same weather data you see here — current conditions, hourly detail, pressure trend, sun and moon, even the raw wind grid. Nothing about the forecast is hidden behind the scoring.

1 Your Weather home screen

The Weather tab opens on current conditions for your active location — temperature, sky, high/low, and rain chance up top, with Pressure, Wind, and Rain Today as tappable cards. Below that, Next 24 Hours and the 7-Day Forecast scroll horizontally, and More links out to Moon, Sun, UV Index, and Air Quality.

Everything starts from current conditions at your active location.
2 Switch locations

Tap the location name at the top of the Weather tab to open Locations. Current Location uses GPS; anything under Saved is a city you've searched and pinned. Tap a saved location to switch to it, or Search city to add a new one.

Switch between Current Location and any saved city.
3 Browse the 7-day forecast

Tap into the 7-Day Forecast for a full week view. Temperature Range charts daily highs and lows together, and Precipitation Chance shows the highest probability and total expected for each day. Tap any day below to expand it into an hourly-style summary without leaving the week view.

Temperature and precipitation charted across the whole week.
4 Dig into hourly detail

From Next 24 Hours, tap any hour to open the full hourly breakdown. Switch tabs across the top — Temp, Precip, Wind, Pressure, Humidity — to chart that metric hour by hour, and drag anywhere on the chart to scrub to a specific time. Every hour below lists feels-like, wind, gusts, humidity, dew point, pressure, UV index, cloud cover, and visibility.

Precip tab — chance by the hour.
Temp tab — slide to explore the curve.
5 Track pressure

Tap the Pressure card for the current reading and its trend, plus a 48-hour chart covering the past 24 hours and the next 24. Past 24 Hours and 7-Day Stats below show min, max, range, low, high, and average — the same pressure trend Pattern Match checks against your logged history.

The same pressure trend that feeds Pattern Match scoring.
6 Sun and Moon

Tap Sun for today's sunrise, sunset, and total daylight, plus a daylight trend note and a 7-day sunrise/sunset table. Tap Moon for the current phase and illumination, a moon path chart showing rise, peak, and set times, current direction and altitude, and illumination for the next 14 days.

Sunrise, sunset, and the daylight trend for the week ahead.
Moon phase, path, and the next 14 days at a glance.
7 Check Precipitation Now

When rain is active or imminent, a Precipitation Now banner surfaces on the home screen — tap it for a 15-minute nowcast of the next hour and an hourly total for the next 24. Rain Totals further down rolls up your past 24 hours, 7 days, month, year, and water year, cross-checked against nearby stations.

Active precipitation, minute by minute.
Clear conditions, with totals cross-checked across stations.
8 See weather history

Tap History to compare today against the same date, and the same week, going back 10 years — temperature range and precipitation, side by side by year. Tap the date at the top to step to a different day and see its own high, low, precip total, and full hourly temperature and precipitation charts.

10 years of history for the same date and the same week.
Step to any date for its own full breakdown.
9 View the wind grid and radar

Tap Wind from the map toolbar for a live grid of wind speed and direction arrows over your actual terrain, with a 12-hour slider to step forward. The layers icon switches between Standard, Hybrid, and Satellite. Zoom out for the regional picture, or switch to Radar for a scrubbable precipitation radar loop over the same map.

Wind arrows plotted right over your terrain.
Standard, Hybrid, or Satellite — pick what reads clearest.
Zoom out for the wind picture across the whole region.
Radar loops back 30 minutes so you can see what's moving in.

Import from onX

Already got your stands mapped out in onX Hunt? Export your waypoints once and bring the whole set into Sage — no re-dropping every pin by hand.

1 Export your waypoints from onX

From a waypoint in onX, tap the share icon. Sharing a waypoint (or a folder of them) generates a link that exports as a standard GPX file — the same format Sage reads in. onX will remind you the shared content is view-only and visible to anyone with the link, which is expected; you're just generating the export.

Any waypoint's detail sheet has the share icon you need.
Share Item generates the GPX export.
2 Save the file somewhere you can find it

Save the exported file to Files — Downloads works fine, or anywhere else you'll remember. Sage reads GPX and KML exports, so anything onX (or another mapping app) hands you in one of those formats will work.

Anywhere in Files works — just note where it lands.
3 Open Import spots from file

In Sage, open Settings and scroll to Import. Tap Import spots from file to open the file picker.

Import lives in Settings, below your map style preferences.
4 Browse to your file

The standard iOS file picker opens. Use Recently Used or Browse to get to wherever you saved the export, then tap the file to select it.

The same file picker you'd use anywhere else in iOS.
5 Review and select waypoints

Sage reads the file and lists everything it found. Anything that looks like it might already exist as a spot gets flagged — Possible duplicate of [name] — and deselected by default, so you don't end up with two copies of the same stand. Use Select All / Deselect All or tap individual checkmarks, then set Hunting or Fishing for each before importing.

Duplicates get flagged and deselected automatically.
6 Review each imported spot

Tap Review on any waypoint before importing to set its exact details — confirm the pinned location, pick a stand type, set seats and optimal wind, tag a camera, and add habitat tags. None of it's required at import time; you can always fill it in later from the spot's own edit screen, but doing it now while onX's location data is already in front of you saves a step.

Everything a manually-created spot has, pre-filled from the import.
